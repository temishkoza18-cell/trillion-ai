# Trillion — Build specification

## Product
Trillion is a personal, local-first, voice-first AI co-founder. It is the main brain; specialist agents are workers. Workers operate independently inside declared roles and tool grants, then return structured evidence to Trillion for the final answer.

## Interface
Retain the Trillion deep-space visual language: calm voice-reactive wireframe orb, slowly turning star clusters, restrained glass-like cards, and explicit status names. Support dark/light, reduced motion, keyboard use, responsive layouts, and text fallback.

## Upgradeability
Discover workers from `agents/<id>/agent.json`, capabilities from `skills/<id>/skill.json`, and integration profiles from `mcp/servers/`. Provider, speech, storage, and interface remain replaceable. Agent doctrine and Scout hunting lanes are editable documents with local overrides and reverts.

## Knowledge
Support a user-selected existing Obsidian Markdown vault, read-only by default, with note sources. Assistant memory is separate, visible, editable, and free of secrets.

## Trust
Workers may act autonomously within narrow declared grants, but cannot expand their own access. Read work runs within scope. Sending, spending, deleting, publishing, and permission changes require approval. Verify outcomes; don't blindly retry uncertain external effects.

## Initial assumptions
- Name: Trillion; personal Windows desktop; local-first runtime.
- Text and UI first, then modular streaming speech.
- Tone: concise, warm, candid, evidence-led.
- Initial specialists: Flux, Relay, Scout, Prism, Atlas, Lift, Forge, Sentinel.
- Obsidian access: existing vault, read-only by default.
